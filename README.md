Flask Blog Application

A simple blog application developed using the Flask framework and SQLite database.

Features

- Create blog posts
- View all blog posts
- View individual post details
- Store posts using SQLite
- Simple HTML and CSS interface

Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
- Git & GitHub

Project Structure

workshopblog-main/
├── app.py
├── blog.db
├── static/
│   └── style.css
└── templates/
    ├── base.html
    ├── create_post.html
    ├── index.html
    └── post_details.html

How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install Flask:

pip install flask

4. Run the application:

python app.py

5. Open the local URL shown in the terminal, usually:

http://127.0.0.1:5000/
